# Formcraft — Smart Form Builder

A polished, browser-first form creation studio for designing, testing and exporting dynamic forms.

## Highlights
- 10 field types: text, long text, email, number, dropdown, choice, checks, date, upload and rating
- Visual question library and focused inspector
- Required fields, helper copy, placeholders and editable answer choices
- Conditional-logic workspace for branching experiences
- Three visual themes with live preview
- Autosaved local drafts
- Import/export structured JSON
- Responsive builder and respondent-facing preview
- GitHub Pages-ready React + TypeScript + Vite architecture

## Run locally
`npm install` then `npm run dev`

## Quality
`npm run test` and `npm run build`

Live demo: https://keyars.github.io/smart-form-builder/
